# SETUP.md — што трэба зрабіць аўтару

> Толькі неабходнае. Што ўжо ёсць: Git, GitHub, Claude Code, акаўнт Twitch Developer. Рэгістрацыі, якія патрэбны пазней, пазначаны як «адкладзена» — рабіць іх зараз не трэба.

## Зараз (перад Крокам 1)

### 1. Парожні рэпазіторый на GitHub
1. Увайдзі на github.com → кнопка **New** (новы repository).
2. Назва: `spotify-bot` (або іншая, якую хочаш).
3. Тып: **Private** (прыватны) — гэта бяспечней, пакуль у праекце няма адчыненага кода.
4. **Не** ставь галачкі «Add a README», «.gitignore», «license» — рэпазіторый павінен быць парожні.
5. Націсні **Create repository** і скапіруй URL (выгляд: `https://github.com/ТВОЙ_ЛОГІН/spotify-bot.git`). Яго трэба будзе даць Claude Code.

### 2. Інструкцыя для Claude Project
1. У claude.ai адкрый праект **spotify-bot** → **Set project instructions** (Інструкцыя праекта).
2. Скапіруй увесь тэкст з файла `docs/CLAUDE_PROJECT_INSTRUCTIONS.md` (пачынаючы з радка пасля лініі `---`) і ўстаў туды. Захавай.
3. Загрузка здымка кантэксту: у ведах праекта (**Project knowledge**) павінен быць файл `CONTEXT.md`. Пры абнаўленні: выдаліць стары, загрузіць новы з `docs/CONTEXT.md`.

### 3. Запуск Claude Code
1. Адкрый тэрмінал у папцы `D:\production\spotify-bot` (у Правадніку: у адрасным радку набяры `cmd` і Enter).
2. Набяры `claude` і Enter.
3. Устаў гатовы промпт, які Claude даў у канцы падрыхтоўкі.

## Адкладзена (рабіць толькі калі Claude папросіць)

- **Twitch Application** — на Этапе 3. Акаўнт Twitch Developer той самы; уключаная двухфактарная аўтэнтыфікацыя (2FA) на акаўнце Twitch звычайна патрэбная для рэгістрацыі прыкладання [ўдакладніць пры рэгістрацыі]. Гл. `DECISIONS.md`, ADR-004.
- **OBS і obs-websocket** — на Этапе 2. Claude Code праверыць версію OBS і дасць інструкцыю ўключэння WebSocket-сервера.
- **Spotify Developer** — толькі калі аналіз існуючага кода пакажа, што патрэбны новыя ключы.

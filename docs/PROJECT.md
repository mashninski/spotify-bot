## Мэта

Лёгкае модульнае прыкладанне для стрымераў на **Twitch** з **OBS**: паказвае на экране, што зараз грае ў **Spotify**, і дазваляе гледачам заказваць песні за **баллы канала**. Прыкладанне распаўсюджваецца сярод іншых стрымераў: просты ўсталёўка, усе падключэнні (Spotify, Twitch) — праз налады ўнутры прыкладання. У будучыні — іншыя крыніцы музыкі (напрыклад, YouTube-плэер) у межах аднаго бота. Код пішацца з нуля.

## Функцыі (узгоднена з аўтарам 2026-10-10)

### MVP
1. **Оверлей** (OBS Browser Source): кампактная палоска ў колерах Spotify з лагатыпам — назва і выканаўца бягучай песні, **візуалізацыя, якая рэагуе на гук** (waveline). Пад ёй драбнейшым шрыфтам — 3 наступныя песні (без слова «далей», але візуальна зразумела, што гэта чарга); каля заказанай песні — дробна нік гледача. Стрымер свабодна размяшчае і рухае оверлей у кожнай сцэне OBS.
2. **Док-панэль** (OBS Custom Browser Dock): што грае зараз; «паўза», «наступная», «папярэдняя»; спіс чаргі; каля кожнай песні — «выдаліць» (крыжык) і «прайграць зараз» (адразу пераключае, астатняя чарга захоўвае парадак); каля бягучай песні — **«+»: дадаць у «Любімыя трэкі» Spotify стрымера** (каб захаваць класную песню ад гледача; калі ўжо дададзена — паказваецца адзнака; узгоднена з аўтарам 2026-10-10); налады.
3. **Сінхранізацыя са Spotify**: калі стрымер пераключае музыку ў самім Spotify, оверлей і док гэта бачаць. Музыку стрымер запускае ў Spotify сам (любы плэйліст); калі заказаў няма — паказваюцца наступныя трэкі з яго кантэксту.
4. **Заказ песні за баллы канала**: узнагароду «Заказаць песню» стварае само прыкладанне. Глядач піша спасылку на трэк або назву. Правілы (мяняюцца ў наладах): цана **1000**; песня **не даўжэй за 12 хвілін**; **не больш за 2** песні аднаго гледача ў чарзе адначасова; песню, якая ўжо ў чарзе, нельга заказаць паўторна; explicit **дазволены** (можна забараніць у наладах). Калі песня не знойдзена або парушае правілы — **баллы вяртаюцца аўтаматычна**.
5. **Паведамленні ў чат ад імя стрымера** (без асобнага бота): «дададзена, №N у чарзе», «не знайшоў, баллы вернуты» і г. д.
6. **Налады ўнутры дока**: «Падключыць Spotify», «Падключыць Twitch», пароль obs-websocket, выбар аўдыякрыніцы для візуалізацыі, правілы заказаў.
7. **Нічога не запускаецца асобна**: усё працуе ўнутры OBS і стартуе разам з ім (ADR-009).
8. Мова гледачоў і інтэрфейсу — **беларуская**; платформа — **Windows** (ADR-010).

### Відэа з YouTube (рашэнне аўтара 2026-10-17, ADR-020)
1. Асобная ўзнагарода Twitch **«Замовіць відэа з YouTube»**, кошт 1000 (мяняецца ў доку), ствараецца і ставіцца на паўзу, як «Замовіць песню».
2. Глядач дасылае толькі **спасылку** на YouTube (пошуку па назве няма — без ключоў API), відэа **не даўжэй за 12 хв**.
3. **Чарга агульная** са Spotify, парадак — па часе замовы. Правілы тыя ж: ліміт 2 замовы ад гледача — **агульны** на песні і відэа, дублі забаронены, адмова — балы вяртаюцца, паведамленні ў чат па-беларуску.
4. Фільтраў зместу няма. Відэа, якое нельга ўбудаваць (забарона, узроставае абмежаванне, трансляцыя, выдалена, задоўгае), — адмова з вяртаннем балаў і паведамленнем.
5. Оверлэй: **5 наступных** замест 3, у кожнай — значок крыніцы (Spotify / YouTube) і нік; у доку — таксама значок, кнопкі дока працуюць і для відэа.
6. Звычайны стан: назва крыху правей, за лагатыпам Spotify — цьмяны лагатып YouTube.
7. Падчас відэа: лагатыпы плаўна мяняюцца месцамі, усё чырвонае, назва відэа і канал з нікам, waveline застаецца; над палоскай плаўна з’яўляецца плашка з відэа. Пасля — плашка знікае, стыль Spotify, музыка працягваецца.

## Стэк і архітэктура

Статычнае вэб-прыкладанне на **TypeScript** (зборка **Vite**, UI — **Preact**, тэсты — **Vitest**), якое выконваецца ўбудаваным браўзерам OBS. «Мозг» (чарга, заказы, падключэнне да OBS) працуе ў адной са старонак — у доку або ў оверлеі; яна выбіраецца праз Web Locks, астатнія паказваюць стан і шлюць каманды праз `BroadcastChannel` (ADR-015, `src/brain/`). Узровень гуку — праз **obs-websocket**. Ніякіх асобных працэсаў. Spotify — Web API з браўзера, уваход PKCE, токены ў `localStorage`, апытанне робіць лідар (ADR-016, `src/providers/spotify/`). Заказы → Spotify: `src/core/requests.ts`, `src/providers/spotify/search.ts` (ADR-017). Twitch — уваход па кодзе, Helix і EventSub WebSocket з браўзера, токены ў `localStorage`, з Twitch размаўляе лідар, журнал заказаў (ADR-018, `src/sources/twitch/`). Відэа YouTube — праверка праз oEmbed і схаваны плэер (без ключоў), грае толькі ў оверлэі (Web Lock `spotify-bot:video`), Spotify на паўзе (ADR-020, `src/youtube/`, `src/core/video.ts`, `src/ui/overlay/video-player.ts`). Падрабязна: `DECISIONS.md`, ADR-007…020. Канал «мозг» → оверлей — obs-browser `emit_event` праз obs-websocket і `BroadcastChannel` (ADR-013). Node.js патрэбны толькі для распрацоўкі і зборкі.

## Каманды запуску і праверкі

Патрабуецца Node.js 24+ (толькі для распрацоўкі). Усе каманды — у папцы праекта.

| Каманда | Што робіць |
|---|---|
| `npm install` | Усталяваць залежнасці (першы раз і пасля змены `package.json`) |
| `npm run dev` | Dev-сервер на `http://127.0.0.1:5173/` (толькі лакальна) |
| `npm test` | Тэсты Vitest (адзін прагон) |
| `npm run test:watch` | Тэсты ў рэжыме назірання |
| `npm run typecheck` | Праверка тыпаў TypeScript |
| `npm run build` | Праверка тыпаў + зборка ў `dist/` |
| `npm run preview` | Паказ зборкі на `http://127.0.0.1:4173/` |

Старонкі (пры `npm run dev`):
- `http://127.0.0.1:5173/dock.html` — док (OBS → Док-панели → Пользовательские док-панели браузера);
- `http://127.0.0.1:5173/overlay.html` — оверлей (Browser Source 520×500, ADR-020); `?debug=1` — дыягностыка, `?demo=1` — тэставыя даныя без дока, `?demo=video` — тэставае відэа (YouTube не працуе з `127.0.0.1` — для відэа адкрываць `http://localhost:…`);
- `http://127.0.0.1:5173/` — спіс спасылак.

Праверка без OBS: адкрыць док і оверлей у дзвюх укладках аднаго браўзера — сувязь ідзе праз `BroadcastChannel`; у наладах дока «Крыніца гуку → імітацыя».
